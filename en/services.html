Service 01

Technology consulting

I help you make technical decisions with complete information: what to build, with which technology, and in what order. The goal is to invest in what your business actually needs and avoid costly mistakes.

What it includes

  • Technology assessment of systems and processes
  • Step-by-step digitalization roadmap
  • Selection of tools, technologies, and vendors
  • Planning and technical review of software projects

When it makes sense

  • You are starting a software project and need to define scope and architecture.
  • Your team or current vendor needs a technical second opinion.
  • You want to digitalize processes and are not sure where to start.

Service 03

Systems scaling and modernization

I modernize legacy systems and prepare your applications to grow, preserving business logic without interrupting operations. I work in particular depth with Java projects, and also with PHP, Visual Basic 6, Access, and .NET.

What it includes

  • Full audit of the current system
  • Java version upgrades (from 6, 7, or 8 to 17, 21, or 25 LTS)
  • Legacy system and data migration with no data loss
  • Incremental codebase modernization and performance optimization

When it makes sense

  • Your Java application runs on an unsupported version or an old application server.
  • Your system is hard to maintain or performance degrades as operations grow.
  • You need to integrate an older system with current services.

Java: version upgrades and legacy projects

Many critical operations still run on Java 6, 7, or 8 and old application servers. I upgrade them in stages, with tests at every step, so the system is supported again without a rewrite from scratch.

Version upgrades

  • Staged path across LTS versions: 8 → 11 → 17 → 21 → 25
  • Replacement of removed or deprecated APIs and javax to jakarta migration
  • Upgrades of Spring Boot, Hibernate, Maven or Gradle, and dependencies
  • Regression tests before and after every version step

Advanced legacy projects

  • Java EE applications (EJB, JSF, Struts, servlets) on WebLogic, WebSphere, or JBoss
  • Gradual migration to Spring Boot and independent services, without a big-bang rewrite
  • Characterization tests for code with no tests or documentation
  • JVM tuning (memory and garbage collection) and container packaging

Service 04

Cloud infrastructure management

I design, deploy, and manage the infrastructure your applications run on, with an emphasis on security, stability, and cost control.

What it includes

  • Deployment on AWS, Google Cloud, or Azure
  • Docker containers and continuous integration and delivery (CI/CD)
  • Monitoring, backups, and recovery planning
  • Security, access control, and cost optimization

When it makes sense

  • Your applications run on servers without maintenance or backups.
  • Deployments are manual and risky.
  • Your infrastructure costs grow without clear control.
